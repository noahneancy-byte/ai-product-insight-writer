# AI Product Insight Writer

面向 AI 产品经理的中文专业写作 Skill，用于将零散观点、产品体验和研究资料，整理为有个人判断、有证据、有结构的公开文章。

## 适用场景

- AI 行业趋势与技术产品化解读
- AI 产品深度分析与竞品评测
- 产品方法论与真实项目复盘
- 已有文章的改写、终审与“去 AI 味”

## 核心特点

- 先形成观点，再组织大纲和正文
- 强调真实体验、证据与取舍判断
- 避免资料堆砌、结构过度对称和空泛总结
- 支持针对“AI 味重、缺少个人观点”的返修流程
- 默认适配 AI 产品经理的专业表达语境

## Skill 调用名称

安装后使用：

`human-writing`

仓库名称用于项目展示，Skill 内部调用名称保持不变。
